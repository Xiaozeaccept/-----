# 晨间自学室 · 飞跃 Flyover

面向备考人群（专升本 / 考研 / 考公等）的个人自律备考站。单文件应用，轻量、免安装、即开即用；支持接入免费云端后端实现账号与数据跨设备同步。

## 功能

- 今日课表：可自填时段（名称 / 时间 / 内容可增删），上传课表图片作参考并自动识别导入
- 每日打卡（连续天数）、距考试倒计时（选考试类型 + 自定目标日期）
- 晨间闹钟（到点响铃 + 弹全屏提醒）
- 自习室：番茄钟、今日目标、学习场景音乐、嵌入网课视频、模拟考试
- 专升本复习：英语（单词 / 默写 / 错词本 / 翻译）、计算机网络、C 语言（含子网掩码划分），知识点带「阅读原文」
- 要闻：按行业分类的今日要闻 + 实时抓取
- 今日诗词：国外名言 / 中国古诗，每日轮换
- 素材库、便签、个人中心（改密码 / 换壁纸 / 闹钟）、管理员后台
- 任意背景可换，字体自动调亮；今日诗词每日轮换

## 数据与账号

- 数据键均带用户前缀隔离，每位用户的数据互不可见、互不影响。
- 密码为加盐 SHA-256 存储于浏览器本地；接入云端后端后可实现跨设备同步，后台可管理用户与数据。

## 关于

飞跃（Flyover）—— 把每一份早起自律，汇聚成向上飞越的力量。
