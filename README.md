# 晨间自学室 · 飞跃 Flyover

面向备考人群（专升本 / 考研 / 考公等）的个人自律备考站。单文件应用，纯前端、无后端、数据存本机并按账号隔离。

## 功能

- 今日课表：可自填时段（名称 / 时间 / 内容可增删），上传课表图片作参考并自动识别导入
- 每日打卡（连续天数）、距考试倒计时（选考试类型 + 自定目标日期）
- 晨间闹钟（到点响铃 + 弹全屏提醒，每天 7 点）
- 自习室：番茄钟、今日目标、学习场景音乐、嵌入网课视频、模拟考试
- 专升本复习：英语（单词 / 默写 / 错词本 / 翻译）、计算机网络、C 语言（含子网掩码划分），每个知识点带「阅读原文」
- 要闻：按行业分类的今日要闻 + 实时抓取
- 今日诗词：国外名言 / 中国古诗，每日轮换
- 素材库、便签、个人中心（改密码 / 换壁纸 / 闹钟）、管理员后台
- 任意背景可换，字体自动调亮；今日诗词每日轮换

## 部署（GitHub Pages）

1. 用 GitHub Desktop 新建仓库，把本文件夹内的 `index.html`（和 `晨间学习.html`）提交推送到仓库。
2. 仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后等待发布。
3. 打开 `https://你的用户名.github.io/仓库名/` 即可访问。

> 说明：纯前端页面，登录注册与数据保存在每位用户的浏览器本地，跨设备不同步；上线后如需后台数据库管理用户与数据，需另接免费后端（如 Supabase / Firebase），本仓库暂不含后端。

## 管理员

内置管理员账号由代码内固定凭据直登后台（admin 页），普通用户访问管理后台会显示无权限。

## 账号与数据

- 数据键均带用户前缀隔离，每位用户的数据互不可见、互不影响。
- 密码为加盐 SHA-256 存储于本机 localStorage，仅用于自用 / 信任环境，请勿存放敏感隐私。
