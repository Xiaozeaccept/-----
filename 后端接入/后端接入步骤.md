# 晨间自学室 · 后端接入步骤（按顺序做）

这套后端用 **Supabase**（免费的 Postgres + 认证 + 数据库），不用买服务器。目的是：

- 账号登录注册跨设备同步（手机/电脑看到同一份数据）
- 管理员在后台查看、管理所有用户数据

> 本文件夹里的文件：
>
> - `schema.sql` — 数据库建表脚本
> - `backend-config.js` — 后端连接配置（改两行）
> - `supabase-integration.js` — 数据同步模块（网站用）
> - `管理员后台.html` — 独立管理后台页面（网站用）

---

## 第 1 步：注册并创建 Supabase 项目

1. 打开 <https://supabase.com> → 用 GitHub 账号登录（免费）。
2. 点 **New project**：填项目名（如 `flyover`）、设数据库密码、地区选 **Southeast Asia (Singapore)** 或 **Northeast Asia (Tokyo)**（快）。
3. 等 1–2 分钟创建完成，进入项目控制台。

## 第 2 步：执行建表脚本（让数据库有表）

1. 左侧菜单点 **SQL Editor** → **New query**。
2. 把 `schema.sql` 的**全部内容**粘贴进去。
3. 点 **Run**。看到绿色对勾即成功（会创建 profiles / user_data / activity_log / admins 四张表，并开启数据隔离策略）。

## 第 3 步：开启邮箱认证（让注册登录可用）

1. 左侧 **Authentication → Providers**：确保 **Email** 是开着的（默认开）。
2. 左侧 **Authentication → Settings**：可关掉 “Confirm email” 让注册后直接可用（测试期方便）。

## 第 4 步：拿到连接信息，填进配置文件

1. 左侧 **Project Settings → API**。
2. 复制 **Project URL**（形如 `https://xxxx.supabase.co`）和 **anon public key**（一长串 `eyJ...`）。
3. 打开本文件夹的 `backend-config.js`，把这两处改成你的值：
   ```js
   window.SUPABASE_URL = "https://xxxx.supabase.co";   // 你的 Project URL
   window.SUPABASE_ANON_KEY = "eyJ...";                // 你的 anon key
   ```

## 第 5 步：把「管理员」账号设进数据库

1. 回到 **SQL Editor → New query**，粘贴下面这句并 Run（把 `accept` 换成你要当管理员的人**注册时用的邮箱**）：
   ```sql
   insert into public.admins (username) values ('accept')
   on conflict (username) do nothing;
   ```
   > 说明：`admins` 表存的是 **username**。如果你的管理员注册邮箱和用户名不同，先用 `accept` 注册后，把它真实的 username 填进这张表。管理员必须用**同一账号**在后台登录。

## 第 6 步：把后端接进网站

网站（`晨间学习.html` / `index.html`）现在是纯前端、用本机存储。要开跨设备同步，把三个文件引进去（在网站 `<script>` 之前加三行）：

```html
<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
<script src="后端接入/backend-config.js"></script>
<script src="后端接入/supabase-integration.js"></script>
```

然后把网站的登录/注册/读写改成走 `window.Backend`（见 `supabase-integration.js` 顶部注释）。未配置后端时网站照常能用本机存储，不报错。

## 第 7 步：使用管理后台

1. 把 `管理员后台.html`、`backend-config.js`、`supabase-integration.js` 放在一起，直接双击打开（或随网站一起部署）。
2. 用管理员的**邮箱 + 密码**登录。
3. 即可看到：注册用户数、数据条目、近 7 天活跃；点 **清空数据** 可清除某个用户的所有云端数据。
   - 普通用户登录后台：`Backend.adminUsers()` 只返回自己一行（权限不足时为空/被拒），不会泄露。

## 第 8 步：部署上线（GitHub Pages）

1. 把网站 + `后端接入/` 一起推到 GitHub 仓库。
2. 仓库 **Settings → Pages → Source 选 main 分支根目录**。
3. 打开 `https://你的用户名.github.io/仓库名/` 即可；跨设备登录看到的是同一份云端数据。

---

## 常见问题

- **登录提示 “Invalid login credentials”**：邮箱或密码不对，或账号还没确认邮箱（去第 3 步开 “Confirm email” 关掉或去邮箱点确认）。
- **后台看不到用户**：确认管理员账号在 `admins` 表里，且用同一账号登录。
- **不想用后端了**：把网站里加的三行 `<script>` 删掉即可，网站回到纯本机模式。
- **数据安全**：用户数据按 user_id 隔离（RLS 已开启），他人看不到；管理员通过 security definer 函数读取，普通用户调不通。
